QR Code কি আৰু ই কেনেকৈ কাম কৰে?

১৭ অক্টোবৰ, ২০২৬

QR Code (Quick Response Code) হৈছে সৰু সৰু ক'লা আৰু বগা কোঠাৰে গঠিত বৰ্গাকাৰ 2D বাৰক'ড। কেৱল দহ-পোন্ধৰটা সংখ্যা সংৰক্ষণ কৰা ৰেখা বাৰক'ডৰ বিপৰীতে, QR Code এ ৱেবছাইটৰ লিংক, দীঘল পাঠ, ফোন নম্বৰ, যোগাযোগ, আনকি WiFi নেটৱৰ্কৰ ডাটাও সংৰক্ষণ কৰিব পাৰে।

QR Code 1994 চনত জাপানী কোম্পানী Denso Wave এ কাৰখানাত গাড়ীৰ যন্ত্ৰাংশ ট্ৰেক কৰিবলৈ উদ্ভাৱন কৰিছিল। এতিয়া ফোনৰ কেমেৰাৰে পোনপটীয়াকৈ স্কেন কৰিব পৰা বাবে, ডিজিটেল পৰিশোধৰ পৰা ৰেষ্টুৰেণ্টৰ মেনুলৈকে সকলোতে QR Code ব্যৱহাৰ হৈছে।

QR Code ৰ অংশসমূহ

  • চুকত থকা তিনিটা ডাঙৰ বৰ্গ (finder pattern): কেমেৰাক QR Code বিচাৰি উলিয়াবলৈ আৰু ইয়াৰ দিশ জানিবলৈ সহায় কৰে, সেয়েহে বেঁকাকৈ বা ওলোটাকৈ স্কেন কৰিলেও QR Code পঢ়িব পাৰি।
  • এলাইনমেণ্ট আৰ্হি (alignment pattern): বেঁকা হোৱা বা কোণৰ পৰা দেখা QR Code পঢ়াত সহায় কৰা সৰু বৰ্গ।
  • ডাটা অঞ্চল: আপুনি সংৰক্ষণ কৰা তথ্য থকা সৰু সৰু কোঠা।
  • নিস্তব্ধ অঞ্চল (quiet zone): পটভূমিৰ পৰা সহজে পৃথক কৰিবলৈ QR Code ৰ চাৰিওফালে থকা খালী ঠাই।

কিমান ডাটা সংৰক্ষণ কৰিব পাৰে?

QR Code ৰ 40 টা আকাৰৰ সংস্কৰণ আছে। আটাইতকৈ ডাঙৰ সংস্কৰণে 7,089 টা সংখ্যা বা প্ৰায় 2,953 বাইট ডাটা সংৰক্ষণ কৰিব পাৰে। ব্যৱহাৰিকভাৱে, সংৰক্ষণ কৰা ডাটা যিমান কম, কোঠাবোৰ সিমান ডাঙৰ আৰু QR Code স্কেন কৰাটো সিমান সহজ। সেয়েহে বৰ দীঘল লিংকতকৈ চুটি লিংক ভাল।

নষ্ট হ'লেও পঢ়িব পাৰি

QR Code এ ত্ৰুটি সংশোধন (error correction) ব্যৱহাৰ কৰে। ইয়াৰ চাৰিটা স্তৰ আছে:

  • L: QR Code ৰ প্ৰায় 7% নষ্ট হ'লেও ডাটা পুনৰুদ্ধাৰ কৰিব পাৰি।
  • M: প্ৰায় 15%। এইটো সাধাৰণ আৰু সন্তুলিত বিকল্প।
  • Q: প্ৰায় 25%।
  • H: প্ৰায় 30%, ল'গো দিবলগীয়া QR Code বা সহজে লেতেৰা হোৱা ঠাইত ছপা কৰিবলগীয়া QR Code ৰ বাবে উপযুক্ত।

সংশোধনৰ স্তৰ যিমান উচ্চ, সিমান বেছি কোঠাৰ প্ৰয়োজন হয়, সেয়েহে QR Code ৰ আৰ্হি অধিক ঘন দেখা যায়।

QR Code ত কি কি সংৰক্ষণ কৰিব পাৰি?

  • ৱেবছাইট, অনলাইন দোকান বা ফৰ্মৰ লিংক।
  • WiFi ডাটা, যাতে অতিথিসকলে পাছৱৰ্ড টাইপ নকৰাকৈ সংযোগ কৰিব পাৰে। WiFi QR Code নিৰ্দেশিকা চাওক।
  • ডিজিটেল ভিজিটিং কাৰ্ড (vCard), ইমেইল, SMS আৰু WhatsApp চেট।
  • মানচিত্ৰত অৱস্থান আৰু অনুষ্ঠানৰ সূচী।

ষ্টেটিক আৰু ডাইনামিক QR Code

ডাটাৰ পৰা পোনপটীয়াকৈ বনোৱা QR Code ক ষ্টেটিক QR Code বোলা হয়: ইয়াৰ বিষয়বস্তু ছবিখনৰ ভিতৰতে থাকে আৰু সলনি কৰিব নোৱাৰি, কিন্তু ইয়াৰ ম্যাদো কেতিয়াও উকলি নাযায়। ডাইনামিক QR Code ত এটা সেৱাৰ চুটি লিংক থাকে যিয়ে আপোনাৰ গন্তব্যলৈ পঠিয়াই দিয়ে; গন্তব্য সলনি কৰিব পাৰি, কিন্তু সেই সেৱা বন্ধ হ'লে QR Code অচল হৈ পৰিব। বেছিভাগ প্ৰয়োজনৰ বাবে ষ্টেটিক QR Code যথেষ্ট আৰু দীৰ্ঘম্যাদীভাৱে অধিক সুৰক্ষিত।

চেষ্টা কৰিব বিচাৰে নেকি? এতিয়াই বিনামূলীয়া QR Code বনাওক, বা 3 টা পদক্ষেপত QR Code বনোৱাৰ উপায় পঢ়ক।

সঘনাই সোধা প্ৰশ্ন

QR Code ৰ ম্যাদ উকলি যায় নেকি?

ষ্টেটিক QR Code ৰ ম্যাদ কেতিয়াও উকলি নাযায়, কাৰণ ইয়াৰ ডাটা পোনপটীয়াকৈ ছবিখনৰ ভিতৰতে থাকে। ডাইনামিক QR Code এ লিংক প্ৰদানকাৰী সেৱা বন্ধ হ'লে বা ছাবস্ক্ৰিপচন শেষ হ'লে কাম কৰা বন্ধ কৰিব পাৰে।

QR Code এ কিমান ডাটা সংৰক্ষণ কৰিব পাৰে?

QR Code ৰ আটাইতকৈ ডাঙৰ সংস্কৰণে 7,089 টা সংখ্যা বা প্ৰায় 2,953 বাইটলৈকে সংৰক্ষণ কৰিব পাৰে। কিন্তু ডাটা যিমান কম, QR Code স্কেন কৰাটো সিমান সহজ।

QR Code ৰ কিছু অংশ নষ্ট হ'লেও পঢ়িব পাৰি নেকি?

হয়। ত্ৰুটি সংশোধনৰ বাবে, ব্যৱহাৰ কৰা সংশোধনৰ স্তৰ L, M, Q বা H ৰ ওপৰত নিৰ্ভৰ কৰি, QR Code ৰ প্ৰায় 7% ৰ পৰা 30% অংশ নষ্ট হ'লেও ইয়াক পঢ়িব পাৰি।
