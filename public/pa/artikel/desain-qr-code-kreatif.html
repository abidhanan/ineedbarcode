ਕਾਲਾ-ਚਿੱਟਾ QR Code ਕੰਮ ਤਾਂ ਕਰਦਾ ਹੈ, ਪਰ ਪੈਕਿੰਗ, ਸੱਦਾ-ਪੱਤਰਾਂ ਜਾਂ ਪ੍ਰਚਾਰ ਸਮੱਗਰੀ ਉੱਤੇ ਅਕਸਰ ਫਿੱਕਾ ਜਿਹਾ ਲੱਗਦਾ ਹੈ। ਥੋੜ੍ਹੀ ਜਿਹੀ ਡਿਜ਼ਾਈਨ ਛੋਹ ਨਾਲ QR Code ਆਪਣਾ ਕੰਮ ਗੁਆਏ ਬਿਨਾਂ ਹੋਰ ਆਕਰਸ਼ਕ ਦਿਸ ਸਕਦਾ ਹੈ। ਅਸਲ ਗੱਲ ਇਹ ਸਮਝਣਾ ਹੈ ਕਿ ਕਿਹੜਾ ਹਿੱਸਾ ਬਦਲਿਆ ਜਾ ਸਕਦਾ ਹੈ ਅਤੇ ਕਿਹੜਾ ਪੂਰਾ ਹੀ ਰਹਿਣਾ ਚਾਹੀਦਾ ਹੈ।

ਬਾਹਰੀ ਸ਼ਕਲ: ਦਿਲ, ਗੋਲ ਅਤੇ ਹੋਰ

QR Code ਜਨਰੇਟਰ ਦੇ ਡਿਜ਼ਾਈਨ ਵਾਲੇ ਹਿੱਸੇ ਵਿੱਚ ਤੁਸੀਂ ਗੋਲ, ਦਿਲ, ਛੇ-ਕੋਣੀ, ਅੱਠ-ਕੋਣੀ, ਤਾਰਾ ਜਾਂ ਹੀਰਾ ਵਰਗੀ ਸ਼ਕਲ ਚੁਣ ਸਕਦੇ ਹੋ। ਅਸਲ QR Code ਵਿਚਕਾਰ ਹੀ ਰਹਿੰਦਾ ਹੈ, ਅਤੇ ਬਾਕੀ ਥਾਂ ਸਜਾਵਟੀ ਪੈਟਰਨ ਨਾਲ ਭਰੀ ਜਾਂਦੀ ਹੈ ਜਦ ਤੱਕ ਚੁਣੀ ਗਈ ਸ਼ਕਲ ਨਾ ਬਣ ਜਾਵੇ। ਸਜਾਵਟੀ ਪੈਟਰਨ ਵਿੱਚ ਕੋਈ ਡਾਟਾ ਨਹੀਂ ਹੁੰਦਾ, ਇਸ ਲਈ ਜਦ ਤੱਕ ਅਸਲ QR Code ਦੇ ਆਲੇ-ਦੁਆਲੇ ਖ਼ਾਲੀ ਵਿੱਥ ਹੋਵੇ, ਇਹ ਸਕੈਨਿੰਗ ਵਿੱਚ ਰੁਕਾਵਟ ਨਹੀਂ ਪਾਉਂਦਾ।

ਬਿੰਦੂਆਂ ਦੀ ਸ਼ੈਲੀ

QR Code ਦੇ ਖ਼ਾਨਿਆਂ ਨੂੰ ਗੋਲਾਈ ਵਾਲੀ ਸ਼ਕਲ ਜਾਂ ਗੋਲ ਬਿੰਦੂਆਂ ਵਿੱਚ ਬਦਲਿਆ ਜਾ ਸਕਦਾ ਹੈ। ਆਸਾਨੀ ਨਾਲ ਸਕੈਨ ਹੁੰਦੇ ਰਹਿਣ ਲਈ, ਕੋਨਿਆਂ ਵਾਲੇ ਤਿੰਨ ਵੱਡੇ ਖ਼ਾਨੇ (finder pattern) ਪੂਰੇ ਖ਼ਾਨਿਆਂ ਵਜੋਂ ਹੀ ਰਹਿਣੇ ਚਾਹੀਦੇ ਹਨ, ਕਿਉਂਕਿ ਕੈਮਰਾ ਸਭ ਤੋਂ ਪਹਿਲਾਂ ਇਨ੍ਹਾਂ ਨੂੰ ਹੀ ਲੱਭਦਾ ਹੈ। ਤੁਸੀਂ ਬਿੰਦੂਆਂ ਦੀ ਕੋਈ ਵੀ ਸ਼ੈਲੀ ਚੁਣੋ, ਸਾਡਾ ਜਨਰੇਟਰ ਇਸ ਹਿੱਸੇ ਨੂੰ ਹਮੇਸ਼ਾ ਪੂਰੇ ਖ਼ਾਨੇ ਵਜੋਂ ਹੀ ਬਣਾਉਂਦਾ ਹੈ, ਵੱਧ ਤੋਂ ਵੱਧ ਗੋਲ ਕੋਨਿਆਂ ਨਾਲ।

ਰੰਗ

  • QR Code ਲਈ ਗੂੜ੍ਹਾ ਅਤੇ ਪਿਛੋਕੜ ਲਈ ਹਲਕਾ ਰੰਗ ਵਰਤੋ। ਗੂੜ੍ਹਾ ਨੀਲਾ, ਗੂੜ੍ਹਾ ਹਰਾ, ਜਾਮਨੀ ਜਾਂ ਗੂੜ੍ਹਾ ਭੂਰਾ ਆਮ ਤੌਰ 'ਤੇ ਸੁਰੱਖਿਅਤ ਹਨ।
  • QR Code ਲਈ ਫਿੱਕੇ ਰੰਗਾਂ ਤੋਂ ਬਚੋ, ਜਿਵੇਂ ਪੀਲਾ, ਫਿੱਕਾ ਗੁਲਾਬੀ ਜਾਂ ਹਲਕਾ ਸਲੇਟੀ।
  • ਰੰਗਾਂ ਨੂੰ ਉਲਟਾ ਕਰਕੇ ਗੂੜ੍ਹੇ ਪਿਛੋਕੜ ਉੱਤੇ ਹਲਕਾ QR Code ਨਾ ਬਣਾਓ, ਕਿਉਂਕਿ ਹਰ ਸਕੈਨਰ ਐਪ ਇਸ ਦਾ ਸਮਰਥਨ ਨਹੀਂ ਕਰਦੀ।

ਫ਼ਰੇਮ ਅਤੇ ਸੱਦਾ

"ਮੈਨੂੰ ਸਕੈਨ ਕਰੋ", "ਮੀਨੂ" ਜਾਂ "SCAN WIFI" ਵਰਗੀ ਸੱਦੇ ਵਾਲੀ ਲਿਖਤ ਵਾਲਾ ਫ਼ਰੇਮ ਲੋਕਾਂ ਨੂੰ QR Code ਦਾ ਕੰਮ ਸਮਝਣ ਵਿੱਚ ਸਾਬਤ ਤੌਰ 'ਤੇ ਮਦਦ ਕਰਦਾ ਹੈ। ਤੁਸੀਂ ਹੇਠਲੇ ਲੇਬਲ, ਉੱਪਰਲੇ ਲੇਬਲ, ਕੋਨੇ, ਗੁਬਾਰੇ, ਗੋਲ ਜਾਂ ਰਿਬਨ ਵਾਲਾ ਫ਼ਰੇਮ ਚੁਣ ਸਕਦੇ ਹੋ, ਅਤੇ ਫਿਰ ਉਸ ਦੀ ਲਿਖਤ ਅਤੇ ਰੰਗ ਬਦਲ ਸਕਦੇ ਹੋ।

ਡਿਜ਼ਾਈਨ ਨੂੰ ਪੜ੍ਹਨਯੋਗ ਰੱਖਣ ਦੇ ਨਿਯਮ

  1. QR Code ਅਤੇ ਉਸ ਦੇ ਪਿਛੋਕੜ ਵਿਚਕਾਰ ਤਕੜਾ ਕੰਟ੍ਰਾਸਟ ਬਣਾਈ ਰੱਖੋ।
  2. ਕੋਨਿਆਂ ਵਾਲੇ ਤਿੰਨ ਨਿਸ਼ਾਨ-ਖ਼ਾਨਿਆਂ ਨੂੰ ਸਾਫ਼ ਅਤੇ ਬਿਨਾਂ ਢਕੇ ਰਹਿਣ ਦਿਓ।
  3. QR Code ਅਤੇ ਫ਼ਰੇਮ ਦੇ ਆਲੇ-ਦੁਆਲੇ ਖ਼ਾਲੀ ਥਾਂ ਛੱਡੋ।
  4. ਡਿਜ਼ਾਈਨ ਕੀਤੇ QR Code ਨੂੰ ਹੱਦੋਂ ਵੱਧ ਛੋਟਾ ਨਾ ਕਰੋ। ਦਿਲ ਵਰਗੀ ਸ਼ਕਲ ਕਾਰਨ ਅਸਲ QR Code ਦਾ ਖੇਤਰ ਪੂਰੀ ਤਸਵੀਰ ਦੇ ਆਕਾਰ ਨਾਲੋਂ ਛੋਟਾ ਹੋ ਜਾਂਦਾ ਹੈ।
  5. ਛਾਪਣ ਤੋਂ ਪਹਿਲਾਂ ਕਈ ਫ਼ੋਨਾਂ ਨਾਲ ਜਾਂਚ ਕਰੋ।

ਜੇ ਤੁਹਾਡਾ ਡਿਜ਼ਾਈਨ ਸਕੈਨ ਕਰਨਾ ਔਖਾ ਹੈ, ਤਾਂ ਕਾਰਨ ਲੱਭਣ ਲਈ ਰੀਸੈੱਟ ਕਰੋ ਬਟਨ ਨਾਲ ਇੱਕ-ਇੱਕ ਕਰਕੇ ਮੁੱਢਲੀਆਂ ਸੈਟਿੰਗਾਂ ਉੱਤੇ ਵਾਪਸ ਜਾਓ। ਹੋਰ ਆਮ ਕਾਰਨ ਬਾਰਕੋਡ ਸਕੈਨ ਨਾ ਹੋਣ ਦੇ 7 ਕਾਰਨ ਵਿੱਚ ਪੜ੍ਹੇ ਜਾ ਸਕਦੇ ਹਨ।

ਕੀ ਦਿਲ ਦੀ ਸ਼ਕਲ ਵਾਲਾ QR Code ਸਕੈਨ ਹੋ ਸਕਦਾ ਹੈ?

ਹਾਂ। ਅਸਲ QR Code ਵਿਚਕਾਰ ਪੂਰਾ ਬਣਿਆ ਰਹਿੰਦਾ ਹੈ ਅਤੇ ਬਾਕੀ ਹਿੱਸਾ ਸਿਰਫ਼ ਸਜਾਵਟੀ ਪੈਟਰਨ ਹੁੰਦਾ ਹੈ। ਜਦ ਤੱਕ ਕੰਟ੍ਰਾਸਟ ਤਕੜਾ ਅਤੇ ਆਕਾਰ ਕਾਫ਼ੀ ਹੋਵੇ, QR Code ਪੜ੍ਹਿਆ ਜਾਂਦਾ ਰਹਿੰਦਾ ਹੈ।

QR Code ਲਈ ਕਿਹੜੇ ਰੰਗ ਸੁਰੱਖਿਅਤ ਹਨ?
