ಬಾರ್‌ಕೋಡ್ ಎಂದರೇನು? ಅರ್ಥ, ಕಾರ್ಯವಿಧಾನ ಮತ್ತು ಅದರ ಪ್ರಕಾರಗಳು

ಅಕ್ಟೋಬರ್ 18, 2026

ಬಾರ್‌ಕೋಡ್ ಎಂದರೆ ಯಂತ್ರ ಓದಬಹುದಾದ ಮಾದರಿಯ ರೂಪದಲ್ಲಿ ಡೇಟಾವನ್ನು ಬರೆಯುವ ಒಂದು ವಿಧಾನ. ಈ ಮಾದರಿ ಸಾಮಾನ್ಯವಾಗಿ ವಿಭಿನ್ನ ಅಗಲದ ಕಪ್ಪು ಮತ್ತು ಬಿಳಿ ಗೆರೆಗಳಾಗಿರುತ್ತದೆ ಅಥವಾ ಒಂದು ಚೌಕದೊಳಗೆ ಜೋಡಿಸಲಾದ ಸಣ್ಣ ಸಣ್ಣ ಚೌಕಗಳಾಗಿರುತ್ತದೆ. ಸ್ಕ್ಯಾನ್ ಮಾಡಿದಾಗ, ಆ ಮಾದರಿಯನ್ನು ಮತ್ತೆ ಸಂಖ್ಯೆ ಅಥವಾ ಪಠ್ಯವಾಗಿ ಪರಿವರ್ತಿಸಲಾಗುತ್ತದೆ, ಉದಾಹರಣೆಗೆ ಉತ್ಪನ್ನದ ಕೋಡ್, ರಸೀದಿ ಸಂಖ್ಯೆ ಅಥವಾ ವೆಬ್‌ಸೈಟ್ ವಿಳಾಸ.

ಯಂತ್ರವೇ ಓದುವುದರಿಂದ, ಕೋಡ್ ಅನ್ನು ಕೈಯಿಂದ ಟೈಪ್ ಮಾಡುವುದಕ್ಕಿಂತ ಬಾರ್‌ಕೋಡ್ ಬಹಳ ವೇಗವಾಗಿದ್ದು ತಪ್ಪುಗಳೂ ಕಡಿಮೆ. ಅದಕ್ಕಾಗಿಯೇ ಕ್ಯಾಷ್ ಕೌಂಟರ್, ಗೋದಾಮು, ಆಸ್ಪತ್ರೆ, ಟಿಕೆಟ್‌ಗಳಿಂದ ಹಿಡಿದು ಆಹಾರ ಪ್ಯಾಕೇಜ್‌ಗಳವರೆಗೆ ಬಾರ್‌ಕೋಡ್ ಬಳಸಲಾಗುತ್ತದೆ.

ಬಾರ್‌ಕೋಡ್‌ನ ಸಂಕ್ಷಿಪ್ತ ಇತಿಹಾಸ

ಬಾರ್‌ಕೋಡ್‌ನ ಕಲ್ಪನೆಗೆ 1952 ರಲ್ಲಿ ಅಮೆರಿಕ ಸಂಯುಕ್ತ ಸಂಸ್ಥಾನದಲ್ಲಿ ನಾರ್ಮನ್ ಜೋಸೆಫ್ ವುಡ್‌ಲ್ಯಾಂಡ್ ಮತ್ತು ಬರ್ನಾರ್ಡ್ ಸಿಲ್ವರ್ ಪೇಟೆಂಟ್ ಪಡೆದರು. ಅಂಗಡಿಗಳಲ್ಲಿ ಬಾರ್‌ಕೋಡ್ ನಿಜವಾಗಿ ಬಳಕೆಗೆ ಬಂದದ್ದು 1974 ರಲ್ಲಿ, ಓಹಾಯೋದ ಒಂದು ಸೂಪರ್‌ಮಾರ್ಕೆಟ್‌ನಲ್ಲಿ ಚೂಯಿಂಗ್ ಗಮ್‌ನ ಒಂದು ಪ್ಯಾಕೆಟ್ ಅನ್ನು UPC ಕೋಡ್‌ನೊಂದಿಗೆ ಸ್ಕ್ಯಾನ್ ಮಾಡಿದಾಗ. ಅಂದಿನಿಂದ ಬಾರ್‌ಕೋಡ್ ಪ್ರಪಂಚದಾದ್ಯಂತ ಹರಡಿದೆ ಮತ್ತು ಇಂದು GS1 ಎಂಬ ಮಾನದಂಡ ಸಂಸ್ಥೆಯು ಅದನ್ನು ಜಾಗತಿಕವಾಗಿ ನಿರ್ವಹಿಸುತ್ತದೆ.

ಬಾರ್‌ಕೋಡ್ ಹೇಗೆ ಕೆಲಸ ಮಾಡುತ್ತದೆ?

ಸ್ಕ್ಯಾನರ್ ಬಾರ್‌ಕೋಡ್ ಮೇಲೆ ಬೆಳಕು ಹಾಯಿಸಿ ಅದರ ಪ್ರತಿಫಲನವನ್ನು ಓದುತ್ತದೆ. ಕಪ್ಪು ಭಾಗ ಕಡಿಮೆ ಬೆಳಕನ್ನು ಪ್ರತಿಫಲಿಸುತ್ತದೆ, ತಿಳಿ ಭಾಗ ಹೆಚ್ಚು ಬೆಳಕನ್ನು ಪ್ರತಿಫಲಿಸುತ್ತದೆ. ಆ ವ್ಯತ್ಯಾಸವನ್ನು 0 ಮತ್ತು 1 ಸಂಖ್ಯೆಗಳ ಸರಣಿಯಾಗಿ ಪರಿವರ್ತಿಸಿ, ಆ ಬಾರ್‌ಕೋಡ್ ಪ್ರಕಾರದ ನಿಯಮಗಳೊಂದಿಗೆ ಹೊಂದಿಸಲಾಗುತ್ತದೆ. ಅನೇಕ ಬಾರ್‌ಕೋಡ್‌ಗಳಲ್ಲಿ ಪರಿಶೀಲನಾ ಅಂಕಿ (check digit) ಸಹ ಇರುತ್ತದೆ, ಅಂದರೆ ಹಿಂದಿನ ಅಂಕಿಗಳಿಂದ ಲೆಕ್ಕ ಹಾಕಲಾದ ಕೊನೆಯ ಅಂಕಿ. ಲೆಕ್ಕದ ಫಲಿತಾಂಶ ಹೊಂದಿಕೆಯಾಗದಿದ್ದರೆ, ಏನೋ ತಪ್ಪಾಗಿದೆ ಎಂದು ಸ್ಕ್ಯಾನರ್‌ಗೆ ತಿಳಿಯುತ್ತದೆ ಮತ್ತು ಅದು ಫಲಿತಾಂಶವನ್ನು ತಿರಸ್ಕರಿಸುತ್ತದೆ.

ಬಾರ್‌ಕೋಡ್ ಸ್ವತಃ ಸಾಮಾನ್ಯವಾಗಿ ಕೇವಲ ಕೋಡ್ ಅನ್ನು ಮಾತ್ರ ಸಂಗ್ರಹಿಸುತ್ತದೆ. ಉತ್ಪನ್ನದ ಹೆಸರು ಅಥವಾ ಬೆಲೆಯಂತಹ ಮಾಹಿತಿಯನ್ನು ಕ್ಯಾಷಿಯರ್ ವ್ಯವಸ್ಥೆ ಅಥವಾ ಡೇಟಾಬೇಸ್‌ನಲ್ಲಿ ಸಂಗ್ರಹಿಸಲಾಗಿರುತ್ತದೆ ಮತ್ತು ಆ ಕೋಡ್ ಆಧಾರದ ಮೇಲೆ ಹುಡುಕಲಾಗುತ್ತದೆ.

ಹೆಚ್ಚಾಗಿ ಬಳಸಲಾಗುವ ಬಾರ್‌ಕೋಡ್ ಪ್ರಕಾರಗಳು

ಸಾಮಾನ್ಯವಾಗಿ ಬಾರ್‌ಕೋಡ್‌ಗಳನ್ನು ಎರಡು ದೊಡ್ಡ ಗುಂಪುಗಳಾಗಿ ವಿಂಗಡಿಸಲಾಗುತ್ತದೆ:

  • 1D (ರೇಖೀಯ) ಬಾರ್‌ಕೋಡ್: ಎಡದಿಂದ ಬಲಕ್ಕೆ ಓದಲಾಗುವ ಲಂಬ ಗೆರೆಗಳ ರೂಪದಲ್ಲಿರುತ್ತದೆ. ಉದಾಹರಣೆಗೆ ಚಿಲ್ಲರೆ ಉತ್ಪನ್ನಗಳಿಗಾಗಿ EAN-13 ಮತ್ತು UPC-A, ಹಾಗೂ ಸರಕು ಸಾಗಣೆ ಮತ್ತು ಗೋದಾಮುಗಳಿಗಾಗಿ Code 128 ಮತ್ತು Code 39.
  • 2D ಬಾರ್‌ಕೋಡ್: ಎರಡು ದಿಕ್ಕುಗಳಲ್ಲಿ ಡೇಟಾವನ್ನು ಸಂಗ್ರಹಿಸುವ ಚೌಕಗಳ ಮಾದರಿ, ಆದ್ದರಿಂದ ಇದರಲ್ಲಿ ಬಹಳ ಹೆಚ್ಚು ಡೇಟಾ ಹಿಡಿಸುತ್ತದೆ. ಉದಾಹರಣೆಗೆ QR Code, Data Matrix, PDF417 ಮತ್ತು Aztec.

ಇದಲ್ಲದೆ ಅಂಚೆ ಮತ್ತು ಸಾಗಣೆ, ಆರೋಗ್ಯ ಸೇವೆಗಳಿಗಾಗಿ ವಿಶೇಷ ಬಾರ್‌ಕೋಡ್‌ಗಳು ಹಾಗೂ ಪೂರೈಕೆ ಸರಪಳಿಗಾಗಿ GS1 ಮಾನದಂಡಗಳೂ ಇವೆ. ಅವುಗಳ ವ್ಯತ್ಯಾಸಗಳ ಕುರಿತು ಹೆಚ್ಚಿನ ವಿವರಗಳನ್ನು ನೀವು 1D ಮತ್ತು 2D ಬಾರ್‌ಕೋಡ್‌ಗಳ ನಡುವಿನ ವ್ಯತ್ಯಾಸ ಲೇಖನದಲ್ಲಿ ಓದಬಹುದು.

ಬಾರ್‌ಕೋಡ್ ಯಾವುದಕ್ಕೆಲ್ಲಾ ಉಪಯುಕ್ತ?

  • ಚಿಲ್ಲರೆ ಮಾರಾಟ: ಬಿಲ್ಲಿಂಗ್ ಅನ್ನು ವೇಗಗೊಳಿಸುತ್ತದೆ ಮತ್ತು ದಾಸ್ತಾನನ್ನು ಸ್ವಯಂಚಾಲಿತವಾಗಿ ದಾಖಲಿಸುತ್ತದೆ.
  • ಗೋದಾಮು ಮತ್ತು ಸಾಗಣೆ: ಸರಕು ಮತ್ತು ಪಾರ್ಸೆಲ್‌ಗಳನ್ನು ಒಂದು ಸ್ಥಳದಿಂದ ಇನ್ನೊಂದು ಸ್ಥಳಕ್ಕೆ ಟ್ರ್ಯಾಕ್ ಮಾಡುತ್ತದೆ.
  • ಟಿಕೆಟ್ ಮತ್ತು ಕಾರ್ಯಕ್ರಮಗಳು: ಒಂದೇ ಸ್ಕ್ಯಾನ್‌ನಲ್ಲಿ ಟಿಕೆಟ್‌ನ ಅಧಿಕೃತತೆಯನ್ನು ಪರಿಶೀಲಿಸುತ್ತದೆ.
  • ಮಾರುಕಟ್ಟೆ ಪ್ರಚಾರ: ಕರಪತ್ರ ಅಥವಾ ಪ್ಯಾಕೇಜಿನ ಮೇಲಿನ QR Code ಜನರನ್ನು ನೇರವಾಗಿ ನಿಮ್ಮ ವೆಬ್‌ಸೈಟ್, ಮೆನು ಅಥವಾ WhatsApp ಗೆ ಕರೆದೊಯ್ಯುತ್ತದೆ.

ನೀವೇ ಬಾರ್‌ಕೋಡ್ ತಯಾರಿಸಿ

ಬಾರ್‌ಕೋಡ್ ತಯಾರಿಸಲು ನಿಮಗೆ ಹಣ ಪಾವತಿಸುವ ಆಪ್ ಅಗತ್ಯವಿಲ್ಲ. I Need Barcode ನಲ್ಲಿ ಬಾರ್‌ಕೋಡ್ ಪ್ರಕಾರವನ್ನು ಆಯ್ಕೆಮಾಡಿ, ಡೇಟಾವನ್ನು ನಮೂದಿಸಿ, ನಂತರ PNG ಚಿತ್ರವಾಗಿ ಡೌನ್‌ಲೋಡ್ ಮಾಡಿ. ಆಯ್ಕೆ ಮಾಡಲು 100 ಕ್ಕೂ ಹೆಚ್ಚು ಪ್ರಕಾರಗಳಿವೆ, ಮತ್ತು ಎಲ್ಲವೂ ನೋಂದಣಿ ಇಲ್ಲದೆ ಉಚಿತ.

ಪದೇ ಪದೇ ಕೇಳಲಾಗುವ ಪ್ರಶ್ನೆಗಳು

ಬಾರ್‌ಕೋಡ್ ಮತ್ತು QR Code ನಡುವಿನ ವ್ಯತ್ಯಾಸವೇನು?

QR Code ಎಂಬುದು ಬಾರ್‌ಕೋಡ್‌ನ ಒಂದು ಪ್ರಕಾರ, ಅಂದರೆ 2D ಬಾರ್‌ಕೋಡ್. ಗೆರೆಗಳ (1D) ಬಾರ್‌ಕೋಡ್ ಕೆಲವೇ ಅಕ್ಷರಗಳನ್ನು ಸಂಗ್ರಹಿಸುತ್ತದೆ ಮತ್ತು ಎಡದಿಂದ ಬಲಕ್ಕೆ ಓದಲಾಗುತ್ತದೆ. ಆದರೆ QR Code ಎರಡು ದಿಕ್ಕುಗಳಲ್ಲಿ ಡೇಟಾವನ್ನು ಸಂಗ್ರಹಿಸುವುದರಿಂದ ಅದರಲ್ಲಿ ಲಿಂಕ್, ಪಠ್ಯ ಅಥವಾ WiFi ಡೇಟಾ ಸಹ ಹಿಡಿಸುತ್ತದೆ.

ಬಾರ್‌ಕೋಡ್ ಉತ್ಪನ್ನದ ಬೆಲೆಯನ್ನು ಸಂಗ್ರಹಿಸುತ್ತದೆಯೇ?

ಸಾಮಾನ್ಯವಾಗಿ ಇಲ್ಲ. ಉತ್ಪನ್ನದ ಬಾರ್‌ಕೋಡ್‌ನಲ್ಲಿ ಕೇವಲ ಕೋಡ್ ಇರುತ್ತದೆ. ಉತ್ಪನ್ನದ ಬೆಲೆ ಮತ್ತು ಹೆಸರನ್ನು ಕ್ಯಾಷಿಯರ್ ವ್ಯವಸ್ಥೆಯಲ್ಲಿ ಸಂಗ್ರಹಿಸಲಾಗಿರುತ್ತದೆ ಮತ್ತು ಸ್ಕ್ಯಾನ್ ಮಾಡಿದ ಕೋಡ್ ಆಧಾರದ ಮೇಲೆ ಹುಡುಕಲಾಗುತ್ತದೆ.

ಬಾರ್‌ಕೋಡ್ ತಯಾರಿಸಲು ಹಣ ಪಾವತಿಸಬೇಕೇ?

ಇಲ್ಲ. ಬಾರ್‌ಕೋಡ್ ಚಿತ್ರವನ್ನು ಉಚಿತವಾಗಿ ತಯಾರಿಸಬಹುದು, ಉದಾಹರಣೆಗೆ I Need Barcode ನಲ್ಲಿ. ಹಣ ಪಾವತಿಸಿ ನೋಂದಾಯಿಸಬೇಕಾದದ್ದು EAN-13 ನಂತಹ ಚಿಲ್ಲರೆ ಉತ್ಪನ್ನ ಬಾರ್‌ಕೋಡ್‌ಗಳ ಅಧಿಕೃತ ಸಂಖ್ಯೆಯನ್ನು ಮಾತ್ರ, ಅದೂ GS1 ಮೂಲಕ.
