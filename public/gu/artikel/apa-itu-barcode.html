બારકોડ શું છે? અર્થ, કાર્યપદ્ધતિ અને તેના પ્રકારો

18 ઑક્ટોબર, 2026

બારકોડ એ ડેટાને એવી પેટર્નના રૂપમાં લખવાની રીત છે જેને મશીન વાંચી શકે. આ પેટર્ન સામાન્ય રીતે જુદી જુદી પહોળાઈની કાળી અને સફેદ લાઇનો હોય છે, અથવા ચોરસમાં ગોઠવાયેલાં નાનાં નાનાં ખાનાં હોય છે. સ્કેન કરતી વખતે આ પેટર્નને ફરી અંકો કે લખાણમાં ફેરવવામાં આવે છે, જેમ કે ઉત્પાદન કોડ, શિપમેન્ટ ટ્રેકિંગ નંબર કે વેબસાઇટનું સરનામું.

મશીન તેને વાંચતું હોવાથી, કોડ હાથે ટાઇપ કરવા કરતાં બારકોડ ઘણો ઝડપી છે અને તેમાં ભૂલો પણ ઓછી થાય છે. એટલે જ બારકોડનો ઉપયોગ બિલિંગ કાઉન્ટર, ગોડાઉન, હોસ્પિટલ, ટિકિટથી લઈને ખાદ્યપદાર્થોના પેકેજિંગ સુધી થાય છે.

બારકોડનો ટૂંકો ઇતિહાસ

બારકોડના વિચારને 1952માં અમેરિકામાં નોર્મન જોસેફ વુડલેન્ડ અને બર્નાર્ડ સિલ્વરે પેટન્ટ કરાવ્યો હતો. દુકાનોમાં બારકોડનો ખરેખર ઉપયોગ 1974માં શરૂ થયો, જ્યારે ઓહાયોના એક સુપરમાર્કેટમાં UPC કોડ વડે ચ્યુઇંગ ગમનું એક પેકેટ સ્કેન કરવામાં આવ્યું. ત્યારથી બારકોડ આખી દુનિયામાં ફેલાયો અને હવે GS1 નામની ધોરણ નક્કી કરતી સંસ્થા તેનું વૈશ્વિક સ્તરે સંચાલન કરે છે.

બારકોડ કેવી રીતે કામ કરે છે?

સ્કેનર બારકોડ પર પ્રકાશ ફેંકે છે અને તેનું પરાવર્તન વાંચે છે. ઘેરો ભાગ ઓછો પ્રકાશ પરાવર્તિત કરે છે અને આછો ભાગ વધુ. આ તફાવતને 0 અને 1ની શ્રેણીમાં ફેરવવામાં આવે છે અને પછી તે બારકોડ પ્રકારના નિયમો સાથે મેળવવામાં આવે છે. ઘણા બારકોડમાં ચેક ડિજિટ (check digit) પણ હોય છે, એટલે કે છેલ્લો અંક જે અગાઉના અંકો પરથી ગણવામાં આવે છે. જો ગણતરીનું પરિણામ મેળ ન ખાય, તો સ્કેનરને ખબર પડી જાય છે કે કંઈક ખોટું છે અને તે પરિણામ નકારી દે છે.

બારકોડ પોતે સામાન્ય રીતે ફક્ત કોડ જ સંગ્રહે છે. ઉત્પાદનનું નામ કે કિંમત જેવી માહિતી બિલિંગ સિસ્ટમ કે ડેટાબેઝમાં સંગ્રહાયેલી હોય છે અને તે કોડના આધારે શોધવામાં આવે છે.

વધુ વપરાતા બારકોડના પ્રકારો

સામાન્ય રીતે બારકોડ બે મોટા જૂથમાં વહેંચાય છે:

  • 1D (લિનિયર) બારકોડ: ઊભી લાઇનોના રૂપમાં હોય છે અને ડાબેથી જમણે વંચાય છે. ઉદાહરણ તરીકે રિટેલ ઉત્પાદનો માટે EAN-13 અને UPC-A, તથા લૉજિસ્ટિક્સ અને ગોડાઉન માટે Code 128 અને Code 39.
  • 2D બારકોડ: ખાનાંવાળી પેટર્નના રૂપમાં હોય છે જે બંને દિશામાં ડેટા સંગ્રહે છે, તેથી તેમાં ઘણું વધારે સમાઈ શકે છે. ઉદાહરણ તરીકે QR Code, Data Matrix, PDF417 અને Aztec.

આ ઉપરાંત ટપાલ અને શિપિંગ, આરોગ્ય સેવા માટેના ખાસ બારકોડ તેમજ સપ્લાય ચેઇન માટેના GS1 ધોરણો પણ છે. તેમના તફાવત વિશે વધુ વિગતવાર સમજૂતી આપ 1D અને 2D બારકોડ વચ્ચેનો તફાવત લેખમાં વાંચી શકો છો.

બારકોડ શાના માટે વપરાય છે?

  • રિટેલ: બિલિંગ ઝડપી બનાવે છે અને સ્ટોકની આપમેળે નોંધ રાખે છે.
  • ગોડાઉન અને શિપિંગ: માલ અને પાર્સલને એક સ્થળેથી બીજા સ્થળ સુધી ટ્રેક કરે છે.
  • ટિકિટ અને કાર્યક્રમો: એક જ સ્કેનમાં ટિકિટ અસલી છે કે નહીં તે તપાસે છે.
  • માર્કેટિંગ: બ્રોશર કે પેકેજિંગ પરનો QR Code લોકોને સીધા આપની વેબસાઇટ, મેનૂ કે WhatsApp પર લઈ જાય છે.

જાતે બારકોડ બનાવો

બારકોડ બનાવવા માટે આપને કોઈ પેઇડ એપ્લિકેશનની જરૂર નથી. I Need Barcode પર બારકોડનો પ્રકાર પસંદ કરો, ડેટા ભરો અને પછી તેને PNG છબી તરીકે ડાઉનલોડ કરો. પસંદ કરવા માટે 100થી વધુ પ્રકારો છે, અને તે બધા નોંધણી વિના મફત છે.

વારંવાર પૂછાતા પ્રશ્નો

બારકોડ અને QR Code વચ્ચે શો તફાવત છે?

QR Code એ બારકોડનો જ એક પ્રકાર છે, એટલે કે 2D બારકોડ. લાઇનવાળો (1D) બારકોડ થોડાક જ અક્ષરો સંગ્રહે છે અને ડાબેથી જમણે વંચાય છે, જ્યારે QR Code બંને દિશામાં ડેટા સંગ્રહે છે, તેથી તેમાં લિંક, લખાણ કે WiFi ડેટા સમાઈ શકે છે.

શું બારકોડમાં ઉત્પાદનની કિંમત સંગ્રહાયેલી હોય છે?

સામાન્ય રીતે નહીં. ઉત્પાદનના બારકોડમાં ફક્ત કોડ હોય છે. ઉત્પાદનની કિંમત અને નામ બિલિંગ સિસ્ટમમાં સંગ્રહાયેલાં હોય છે અને સ્કેન થયેલા કોડના આધારે શોધવામાં આવે છે.

શું બારકોડ બનાવવા માટે પૈસા ચૂકવવા પડે છે?

ના. બારકોડની છબી મફતમાં બનાવી શકાય છે, ઉદાહરણ તરીકે I Need Barcode પર. ફક્ત EAN-13 જેવા રિટેલ ઉત્પાદન બારકોડ માટેનો સત્તાવાર નંબર GS1 મારફતે ફી ભરીને નોંધાવવો પડે છે.
