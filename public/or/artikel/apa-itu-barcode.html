ବାରକୋଡ୍ କ'ଣ? ଅର୍ଥ, କାର୍ଯ୍ୟପ୍ରଣାଳୀ ଏବଂ ପ୍ରକାର

ଅକ୍ଟୋବର 18, 2026

ବାରକୋଡ୍ ହେଉଛି ମେସିନ୍ ପଢ଼ିପାରୁଥିବା ଏକ ନମୁନା ଆକାରରେ ଡାଟା ଲେଖିବାର ପଦ୍ଧତି। ସେହି ନମୁନା ସାଧାରଣତଃ ଭିନ୍ନ ଭିନ୍ନ ଓସାରର କଳା ଓ ଧଳା ରେଖା, କିମ୍ବା ଏକ ବର୍ଗକ୍ଷେତ୍ର ଭିତରେ ସଜାଯାଇଥିବା ଛୋଟ ଛୋଟ ଖୋପ ଆକାରରେ ଥାଏ। ସ୍କାନ୍ କଲାବେଳେ, ସେହି ନମୁନାକୁ ପୁଣି ସଂଖ୍ୟା କିମ୍ବା ଟେକ୍ସଟ୍‌ରେ ବଦଳାଯାଏ, ଯେପରି ଉତ୍ପାଦ କୋଡ୍, ପାର୍ସଲ ଟ୍ରାକିଂ ନମ୍ବର କିମ୍ବା ୱେବସାଇଟ୍ ଠିକଣା।

ମେସିନ୍ ପଢ଼ୁଥିବାରୁ, ହାତରେ କୋଡ୍ ଟାଇପ୍ କରିବା ଅପେକ୍ଷା ବାରକୋଡ୍ ବହୁତ ଶୀଘ୍ର ଏବଂ କମ୍ ତ୍ରୁଟିରେ କାମ କରେ। ସେଥିପାଇଁ ବାରକୋଡ୍ ବିଲିଂ କାଉଣ୍ଟର, ଗୋଦାମ, ହସ୍ପିଟାଲ, ଟିକେଟ୍ ଠାରୁ ଆରମ୍ଭ କରି ଖାଦ୍ୟ ପ୍ୟାକେଜିଂ ପର୍ଯ୍ୟନ୍ତ ବ୍ୟବହୃତ ହୁଏ।

ବାରକୋଡ୍‌ର ସଂକ୍ଷିପ୍ତ ଇତିହାସ

ବାରକୋଡ୍‌ର ଧାରଣାକୁ 1952 ମସିହାରେ ଆମେରିକାରେ ନରମାନ ଜୋସେଫ ଉଡଲ୍ୟାଣ୍ଡ ଏବଂ ବର୍ଣ୍ଣାର୍ଡ ସିଲଭର ପେଟେଣ୍ଟ କରିଥିଲେ। ବାରକୋଡ୍ ପ୍ରକୃତରେ ଦୋକାନରେ ବ୍ୟବହାର ହେବା 1974 ରେ ଆରମ୍ଭ ହେଲା, ଯେତେବେଳେ ଓହାୟୋର ଏକ ସୁପରମାର୍କେଟରେ UPC କୋଡ୍ ସହିତ ଏକ ଚୁଇଂ ଗମ୍ ପ୍ୟାକେଟ୍ ସ୍କାନ୍ କରାଗଲା। ସେବେଠାରୁ ବାରକୋଡ୍ ସାରା ବିଶ୍ୱରେ ବ୍ୟାପିଗଲା ଏବଂ ଏବେ GS1 ନାମକ ଏକ ମାନକ ସଂସ୍ଥା ଦ୍ୱାରା ବିଶ୍ୱସ୍ତରରେ ପରିଚାଳିତ ହେଉଛି।

ବାରକୋଡ୍ କିପରି କାମ କରେ?

ସ୍କାନର୍ ବାରକୋଡ୍ ଉପରେ ଆଲୋକ ପକାଇ ତାହାର ପ୍ରତିଫଳନ ପଢ଼େ। ଗାଢ଼ ଅଂଶ କମ୍ ଆଲୋକ ପ୍ରତିଫଳିତ କରେ, ହାଲୁକା ଅଂଶ ଅଧିକ ଆଲୋକ ପ୍ରତିଫଳିତ କରେ। ସେହି ପାର୍ଥକ୍ୟକୁ 0 ଓ 1 ସଂଖ୍ୟାର କ୍ରମରେ ବଦଳାଇ, ସେହି ବାରକୋଡ୍ ପ୍ରକାରର ନିୟମ ସହିତ ମିଳାଯାଏ। ଅନେକ ବାରକୋଡ୍‌ରେ ଚେକ୍ ଡିଜିଟ୍ (check digit) ମଧ୍ୟ ଥାଏ, ଅର୍ଥାତ୍ ପୂର୍ବବର୍ତ୍ତୀ ସଂଖ୍ୟାଗୁଡ଼ିକରୁ ହିସାବ କରାଯାଉଥିବା ଶେଷ ସଂଖ୍ୟା। ହିସାବ ମେଳ ନ ଖାଇଲେ, ସ୍କାନର୍ ଜାଣିପାରେ ଯେ କିଛି ଭୁଲ ଅଛି ଏବଂ ଫଳାଫଳକୁ ପ୍ରତ୍ୟାଖ୍ୟାନ କରେ।

ବାରକୋଡ୍ ନିଜେ ସାଧାରଣତଃ କେବଳ କୋଡ୍ ସଂରକ୍ଷଣ କରେ। ଉତ୍ପାଦର ନାମ କିମ୍ବା ମୂଲ୍ୟ ଭଳି ସୂଚନା ବିଲିଂ ସିଷ୍ଟମ କିମ୍ବା ଡାଟାବେସ୍‌ରେ ସଂରକ୍ଷିତ ଥାଏ ଏବଂ ସେହି କୋଡ୍ ଆଧାରରେ ଖୋଜାଯାଏ।

ଅଧିକ ବ୍ୟବହୃତ ବାରକୋଡ୍ ପ୍ରକାର

ସାଧାରଣତଃ ବାରକୋଡ୍ ଦୁଇଟି ବଡ଼ ଗୋଷ୍ଠୀରେ ବିଭକ୍ତ:

  • 1D (ରୈଖିକ) ବାରକୋଡ୍: ବାମରୁ ଡାହାଣକୁ ପଢ଼ାଯାଉଥିବା ଠିଆ ରେଖା ଆକାରରେ ଥାଏ। ଉଦାହରଣ ସ୍ୱରୂପ ଖୁଚୁରା ଉତ୍ପାଦ ପାଇଁ EAN-13 ଓ UPC-A, ଏବଂ ଲଜିଷ୍ଟିକ୍ସ ଓ ଗୋଦାମ ପାଇଁ Code 128 ଓ Code 39।
  • 2D ବାରକୋଡ୍: ଦୁଇ ଦିଗରେ ଡାଟା ସଂରକ୍ଷଣ କରୁଥିବା ଖୋପ ନମୁନା, ତେଣୁ ଏଥିରେ ବହୁତ ଅଧିକ ଡାଟା ଧରେ। ଉଦାହରଣ ସ୍ୱରୂପ QR Code, Data Matrix, PDF417 ଏବଂ Aztec।

ଏହା ବ୍ୟତୀତ ଡାକ ଓ ପରିବହନ, ସ୍ୱାସ୍ଥ୍ୟସେବା ପାଇଁ ବିଶେଷ ବାରକୋଡ୍, ଏବଂ ଯୋଗାଣ ଶୃଙ୍ଖଳା ପାଇଁ GS1 ମାନକ ରହିଛି। ସେଗୁଡ଼ିକର ପାର୍ଥକ୍ୟ ବିଷୟରେ ଅଧିକ ବିସ୍ତୃତ ଭାବେ 1D ଏବଂ 2D ବାରକୋଡ୍ ମଧ୍ୟରେ ପାର୍ଥକ୍ୟ ପ୍ରବନ୍ଧରେ ପଢ଼ିପାରିବେ।

ବାରକୋଡ୍ କେଉଁ କାମରେ ଲାଗେ?

  • ଖୁଚୁରା: ବିଲିଂକୁ ଦ୍ରୁତ କରେ ଏବଂ ଷ୍ଟକ୍ ସ୍ୱୟଂଚାଳିତ ଭାବେ ରେକର୍ଡ କରେ।
  • ଗୋଦାମ ଓ ପରିବହନ: ଜିନିଷ ଓ ପାର୍ସଲକୁ ଏକ ସ୍ଥାନରୁ ଅନ୍ୟ ସ୍ଥାନକୁ ଟ୍ରାକ୍ କରେ।
  • ଟିକେଟ୍ ଓ କାର୍ଯ୍ୟକ୍ରମ: ଗୋଟିଏ ସ୍କାନ୍‌ରେ ଟିକେଟ୍‌ର ପ୍ରାମାଣିକତା ଯାଞ୍ଚ କରେ।
  • ମାର୍କେଟିଂ: ବ୍ରୋସର୍ କିମ୍ବା ପ୍ୟାକେଜିଂରେ ଥିବା QR Code ଲୋକଙ୍କୁ ସିଧାସଳଖ ଆପଣଙ୍କ ୱେବସାଇଟ୍, ମେନୁ କିମ୍ବା WhatsApp କୁ ନେଇଯାଏ।

ନିଜେ ବାରକୋଡ୍ ତିଆରି କରନ୍ତୁ

ବାରକୋଡ୍ ତିଆରି କରିବା ପାଇଁ ଆପଣଙ୍କୁ ଦେୟଯୁକ୍ତ ଆପ୍‌ର ଆବଶ୍ୟକତା ନାହିଁ। I Need Barcode ରେ ବାରକୋଡ୍ ପ୍ରକାର ବାଛନ୍ତୁ, ଡାଟା ଭରନ୍ତୁ, ତାପରେ PNG ଛବି ଭାବେ ଡାଉନଲୋଡ୍ କରନ୍ତୁ। ବାଛିବା ପାଇଁ 100 ରୁ ଅଧିକ ପ୍ରକାର ଅଛି, ଏବଂ ସବୁ ମାଗଣା, ପଞ୍ଜୀକରଣ ବିନା।

ବାରମ୍ବାର ପଚରାଯାଉଥିବା ପ୍ରଶ୍ନ

ବାରକୋଡ୍ ଏବଂ QR Code ମଧ୍ୟରେ ପାର୍ଥକ୍ୟ କ'ଣ?

QR Code ହେଉଛି ବାରକୋଡ୍‌ର ଏକ ପ୍ରକାର, ଅର୍ଥାତ୍ 2D ବାରକୋଡ୍। ରେଖା (1D) ବାରକୋଡ୍ କେବଳ ଅଳ୍ପ କିଛି ଅକ୍ଷର ସଂରକ୍ଷଣ କରେ ଏବଂ ବାମରୁ ଡାହାଣକୁ ପଢ଼ାଯାଏ, କିନ୍ତୁ QR Code ଦୁଇ ଦିଗରେ ଡାଟା ସଂରକ୍ଷଣ କରୁଥିବାରୁ ଏଥିରେ ଲିଙ୍କ, ଟେକ୍ସଟ୍ କିମ୍ବା WiFi ଡାଟା ମଧ୍ୟ ଧରିପାରେ।

ବାରକୋଡ୍‌ରେ ଉତ୍ପାଦର ମୂଲ୍ୟ ସଂରକ୍ଷିତ ଥାଏ କି?

ସାଧାରଣତଃ ନାହିଁ। ଉତ୍ପାଦ ବାରକୋଡ୍‌ରେ କେବଳ କୋଡ୍ ଥାଏ। ଉତ୍ପାଦର ମୂଲ୍ୟ ଓ ନାମ ବିଲିଂ ସିଷ୍ଟମରେ ସଂରକ୍ଷିତ ଥାଏ ଏବଂ ସ୍କାନ୍ ହୋଇଥିବା କୋଡ୍ ଆଧାରରେ ଖୋଜାଯାଏ।

ବାରକୋଡ୍ ତିଆରି କରିବା ପାଇଁ ଟଙ୍କା ଦେବାକୁ ପଡ଼େ କି?

ନାହିଁ। ବାରକୋଡ୍ ଛବି ମାଗଣାରେ ତିଆରି କରାଯାଇପାରିବ, ଯେପରି I Need Barcode ରେ। ଟଙ୍କା ଦେଇ ପଞ୍ଜୀକରଣ କରିବାକୁ ପଡ଼େ କେବଳ GS1 ମାଧ୍ୟମରେ EAN-13 ଭଳି ଖୁଚୁରା ଉତ୍ପାଦ ବାରକୋଡ୍‌ର ଆଧିକାରିକ ନମ୍ବର ପାଇଁ।
